# 🎁 GiftMAM

**Gift Many A Mouse: Reforged**  
A modern, lightweight userscript designed to streamline the gifting and sharing experience on MyAnonamouse.

## ✨ Features

- **Modern UI Panel:** A sleek, adaptive interface built with crisp vector icons, fluid transitions, and a minimized "liquid fill" progress badge.
- **Batch Gifting Controls:** Effortlessly distribute Bonus Points to new users with customizable limits, precise rate tracking, and daily cap safeguards.
- **Forum Integration:** Inline controls for instant BP and Freeleech Wedge gifting directly from forum posts. Includes specialized verification tools for specific upload rules.
- **Shoutbox Enhancements:** Custom context menus for quick gifting straight from the chat, plus a native one-click shoutbox reconnect utility.
- **Store & Resource Management:** Streamlined interface to manage VIP renewals, upload credit purchases, and receive Vault/Lotto reminders.
- **Data Persistence:** Safely tracks your gifting history to prevent duplicate sends, featuring complete Import, Export, and Wipe data management.
- **Tab Concurrency:** Built with native Web Locks to ensure reliable, conflict-free performance even when running across multiple tabs.

## 🚀 Installation

1. Ensure you have a userscript manager installed (such as [Tampermonkey](https://www.tampermonkey.net/)).
2. [Click here to install GiftMAM](https://github.com/Photaz/GiftMAM/raw/main/GiftMAM.user.js).
3. Refresh MyAnonamouse to access the new panel.
